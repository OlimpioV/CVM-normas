## Inspiração

A organização do acervo em arquivos Markdown versionados, com um cabeçalho de metadados e o link para a fonte oficial de cada texto, foi inspirada no projeto **[ctresb/leis](https://github.com/ctresb/leis)**, de **João Davi**. Ele reúne a legislação brasileira em Markdown. Fica aqui o reconhecimento e o agradecimento.

Este projeto não copia código daquele repositório. O código, a coleta, o banco, a conversão, a consolidação e a interface foram escritos para o acervo da CVM. Quem reutilizar este projeto deve manter também esta menção ao ctresb/leis.

## Fontes oficiais

Os textos vêm da **Comissão de Valores Mobiliários (CVM)**, em `conteudo.cvm.gov.br` e nos arquivos oficiais lá publicados. São atos oficiais, sem proteção autoral (Lei nº 9.610/1998, art. 8º, IV). Este projeto **não tem vínculo com a CVM** e não é uma publicação oficial. Em caso de divergência, prevalece o texto publicado pela CVM.

## Software de terceiros

O projeto usa bibliotecas livres, cada uma com sua licença: PyMuPDF (AGPL v3), FastAPI, Uvicorn, Jinja2, lxml, Beautiful Soup, markdown-it-py, python-docx e fpdf2, entre outras (veja `requirements.txt`). O OCR usa o modelo de português do projeto [tesseract-ocr/tessdata_best](https://github.com/tesseract-ocr/tessdata_best) (Apache 2.0), baixado na instalação e não incluído neste repositório.
